# Nano Redactor

Chrome Built-in AI（Gemini Nano）を使い、貼り付けた文章から個人情報に該当する部分だけを端末内で検出・マスキングする静的Webアプリです。

## 特徴

- 文章はアプリの外部サーバーへ送信しません。
- Gemini Nanoは「マスク対象の原文文字列」の検出だけを担当します。
- 実際の置換はJavaScriptが原文の完全一致範囲に対して決定論的に行います。
- マスク対象外の文字列、改行、空白、句読点等は原文からそのままコピーします。
- 文頭からchunk単位で逐次処理し、結果を順に表示します。
- Prompt API非対応時は、メールアドレス・電話番号等の形式ベース検出のみで動作します。
- 入力本文はlocalStorage / IndexedDB等へ保存しません。

## 動作環境

Chrome Built-in AI Prompt APIを利用できるデスクトップ版Chromeを推奨します。初回はChromeがGemini Nanoを取得する場合があります。

Prompt APIが利用できない場合でもアプリは起動し、形式ベース検出へフォールバックします。

## マスク形式

- 種別ラベル: `[氏名]`, `[住所]`, `[電話番号]` 等
- 連番ラベル: `[PERSON_01]`, `[ADDRESS_01]` 等
- 黒塗り: `████`

同じ完全一致文字列は、連番ラベル方式では同じラベルを再利用します。異表記の同一人物推定は行いません。

## テスト

Node.js 22以降を想定しています。

```bash
cd nano-redactor
npm test
```

最重要のテスト対象は「マスク対象span以外の原文が変更されないこと」です。
