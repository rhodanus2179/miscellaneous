# Condition Pulse

朝・昼・夜に3問ずつ答え、本人の平常値との差と一日のコンディションの揺らぎを観察する、端末内完結型のWebアプリです。

## 特徴

- 1回3問、5〜10秒程度のチェックイン
- 66問の日本語質問バンクから時間帯・履歴・表示設定に応じて選択
- IndexedDBによる端末内保存（サーバー送信なし）
- 今日の流れ、7日間の傾向、14日間の変化パターン
- 個人・時間帯別の平常値と観測充足度
- 回答中の「一つ前へ」、完了直後の修正・取り消し
- 質問ごとの「頻度を減らす」「表示しない」設定
- JSONバックアップの書き出し・復元、CSV書き出し、完全削除
- Service Workerによるオフライン基本対応と更新通知
- GitHub Actionsによる質問・静的資産・構文・単体テストの検証
- 外部ライブラリ、外部フォント、アクセス解析なし

## 起動

ES ModulesとService Workerを使用するため、ローカルではHTTPサーバー経由で開きます。

```bash
cd condition-pulse
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## テスト

Node.js 20以降で実行できます。

```bash
npm run check
```

## 注意

本アプリは日々のコンディションを振り返るためのウェルネスツールであり、病気の診断、疾病リスクの算定、受診判断を行うものではありません。
