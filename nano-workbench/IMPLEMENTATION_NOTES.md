# Implementation Notes — v0.1.0

## 設計書からの意図的な差分

### Markdown依存を同梱しない

`DESIGN.md`ではMarked + DOMPurifyのvendoringを想定していたが、v0.1.0実装ではraw HTMLを一切解釈しない小規模レンダラーを採用した。

理由:
- 外部ランタイム依存をゼロにする
- GitHub Pagesでの静的配信を単純にする
- raw HTMLを入力段階で機能対象外にし、スクリプト実行経路を減らす

対応範囲は見出し、段落、強調、リスト、引用、インラインコード、コードフェンス、表、リンク、水平線。CommonMark完全準拠は目標にしない。

### PWAアイコン

GitHub connectorでテキストファイルとして管理できるよう、初版はPNGではなくSVGアイコンを利用する。

## 実機で確定する項目

Prompt APIのモデル本体はChromeが更新するため、コンテキスト長・画像コスト・生成速度をコードへ固定しない。右ペインの値を実機計測の正とする。
